# CLAUDE.md

Источник истины по проекту — `tech.md` в корне репозитория. Прочитай его перед началом любой работы и следуй ему дословно: стек, структура папок, логика подсчёта, пороги, DoD.

Проект простой и одиночный (один разработчик), процессов на команду нет. Никаких `CONTRACT GAP`, `LEAD.md`, ревью — просто пиши код по `tech.md`.

Правила:

- не выдумывай стек и структуру папок мимо `tech.md` — если чего-то не хватает, сначала дополни `tech.md`, потом пиши код
- риск с камерой в Telegram iOS WebView (раздел 6 `tech.md`) проверяется первым, до остальной логики
- пороги подсчёта повторений (углы, тайминги) — константы, подбираются по факту тестирования, не хардкодятся «на глаз» без проверки
- код и комментарии на английском, коммиты — Conventional Commits
- реализуй по одной стадии за раз (раздел 9 `tech.md`), не пытайся сделать всё приложение одним диффом
